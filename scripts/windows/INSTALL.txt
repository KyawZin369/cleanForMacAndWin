Khine for Windows
=================

No setup required — WinMole is already bundled inside this app.

Quick start (setup.exe install)
-------------------------------
1. Double-click Khine-<version>-windows-setup.exe
2. Follow the installer wizard
3. Launch Khine from the Start menu (or desktop shortcut if you chose one)

Quick start (portable zip)
--------------------------
1. Extract the zip to any folder
2. Double-click Khine.exe

Requirements
------------
- Windows 10 or Windows 11 (64-bit)
- Nothing else to install (no Flutter, Git, or WinMole)

First launch on another PC
--------------------------
If your build is unsigned, Windows SmartScreen may warn that the publisher
is unknown. To run the app:
1. Click "More info"
2. Click "Run anyway"

After the first successful launch, Windows usually remembers your choice.

What is included
----------------
This package includes the WinMole CLI runtime inside the winmole\ folder.
You do not need to install WinMole separately.

Support
-------
Clean, Uninstall, Analyze, and Status features use the bundled WinMole tools.
